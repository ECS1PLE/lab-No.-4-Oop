# Расписание ЛЭТИ — консольное приложение и Telegram-бот

Учебный проект по объектно-ориентированному программированию, лабораторная работа № 4. Приложение получает расписание учебных групп из API ЛЭТИ и позволяет просматривать его в терминале или Telegram.

## Возможности

- Расписание группы на выбранный день или всю неделю.
- Выбор первой, второй или обеих учебных недель.
- Расписание на сегодня и завтра в Telegram с учётом часового пояса `Europe/Moscow`.
- Поиск конкретного занятия в Telegram: название, тип, время, неделя, аудитория и преподаватель.
- Проверка аргументов команд и сообщения об ошибках ввода или отсутствии расписания группы.

## Требования

- Python **3.10 или новее**: в коде используются `match` и аннотации вида `int | None`.
- Доступ к интернету для запросов к API ЛЭТИ и работы с Telegram.
- Токен Telegram-бота, полученный у [@BotFather](https://t.me/BotFather).

Зависимости перечислены в [requirements.txt](requirements.txt): `requests`, `pyTelegramBotAPI` и `python-dotenv`.

> В текущей реализации `main.py` импортирует модуль бота при запуске любого режима. Поэтому зависимости Telegram-бота и корректный `BOT_TOKEN` нужны также для консольного режима и вызова `--help`.

## Установка и настройка

Выполняйте команды из каталога проекта.

1. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

2. Активируйте его.

   Linux / macOS:

   ```bash
   source .venv/bin/activate
   ```

   Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

3. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Создайте файл `.env` в корне проекта и укажите свой токен:

   ```dotenv
   BOT_TOKEN=ваш_токен_от_BotFather
   ```

   Вместо файла можно задать переменную окружения `BOT_TOKEN`. Не публикуйте токен и не добавляйте `.env` в коммиты: файл указан в `.gitignore`.

## Консольный режим

```bash
python main.py --cli
```

Приложение последовательно запрашивает:

1. Номер группы, например `5353`.
2. Номер недели: `1`, `2` или `3` для обеих недель.
3. День недели по-русски, например `понедельник`. Пустой ввод выводит всю выбранную неделю.

Пример ввода для расписания на понедельник первой недели:

```text
Введите номер группы: 5353
Введите неделю (1, 2 или 3 для обеих): 1
Введите день недели или нажмите Enter для всей недели: понедельник
```

В расписании отображаются день, время, название занятия и номер недели. Если в существующем дне нет занятий, выводится «Нет занятий».

После обработки запроса приложение снова предлагает ввести группу. Для завершения нажмите `Ctrl+C`.

## Telegram-бот

```bash
python main.py --bot
```

После сообщения «Бот запущен. Ожидание сообщений...» откройте своего бота в Telegram и отправьте `/start` или `/help`. Бот получает сообщения через polling; процесс должен оставаться запущенным. Для остановки нажмите `Ctrl+C`.

Общий формат команд расписания: `/<команда> <неделя> <группа>`. Неделя — `1`, `2` или `3` для обеих; номер группы — ровно четыре цифры.

| Команда | Назначение | Пример |
| --- | --- | --- |
| `/start` | Приветствие | `/start` |
| `/help` | Список команд | `/help` |
| `/monday` | Понедельник | `/monday 1 5353` |
| `/tuesday` | Вторник | `/tuesday 1 5353` |
| `/wednesday` | Среда | `/wednesday 2 5353` |
| `/thursday` | Четверг | `/thursday 2 5353` |
| `/friday` | Пятница | `/friday 1 5353` |
| `/saturday` | Суббота | `/saturday 1 5353` |
| `/sunday` | Воскресенье | `/sunday 3 5353` |
| `/week` | Вся выбранная неделя | `/week 3 5353` |
| `/today` | Сегодня | `/today 1 5353` |
| `/tomorrow` | Завтра | `/tomorrow 2 5353` |
| `/lesson` | Информация о занятии | `/lesson 2 5353 понедельник Высшая математика` |

Для `/lesson` укажите неделю, группу, день по-русски и полное название занятия. Название может содержать пробелы; кавычки не нужны. Поиск учитывает регистр и требует точного совпадения с названием в расписании. Если найдено несколько совпадений, возвращается первое.

## Как устроен проект

| Файл | Назначение |
| --- | --- |
| [main.py](main.py) | Точка входа, выбор режима через `argparse` |
| [cli.py](cli.py) | Класс `ScheduleConsole`: консольный ввод и вывод |
| [bot.py](bot.py) | Обработчики команд Telegram и запуск polling |
| [bot_getter.py](bot_getter.py) | Класс `ScheduleCommand`: разбор команд, проверка аргументов и обращение к сервису |
| [query.py](query.py) | Класс `ScheduleService`: запросы к API, фильтрация расписания, поиск и форматирование занятий |
| [const.py](const.py) | Адрес API, названия дней и описание команд |
| [show_commands.py](show_commands.py) | Класс `CommandHelp`: формирование справки бота |
| [requirements.txt](requirements.txt) | Зависимости Python |

Оба интерфейса используют общий `ScheduleService`. Он запрашивает `https://digital.etu.ru/api/mobile/schedule` с параметрами `groupNumber` и `joinWeeks=false`, после чего фильтрует занятия по выбранной неделе. Тайм-аут HTTP-запроса — 10 секунд. Каждый запрос расписания обращается к API заново; локального кэша нет.

## Особенности и устранение ошибок

- **Неделя задаётся вручную.** Команды `/today` и `/tomorrow` определяют только день недели. Текущая учебная неделя и её смена при переходе с воскресенья на понедельник автоматически не вычисляются.
- **Данные зависят от API ЛЭТИ.** Если группа не найдена, приложение сообщает об этом. Если выбранный день отсутствует в ответе API, выводится ошибка об отсутствии дня.
- **`KeyError: 'BOT_TOKEN'` при запуске.** Укажите токен в `.env` или переменной окружения, в том числе при использовании `--cli`. Значение должно быть настоящим токеном от BotFather, а не текстом из примера настройки.
- **Ошибки соединения, тайм-ауты и HTTP-ошибки.** Проверьте доступность сети и API. Эти исключения `requests` сейчас не преобразуются в пользовательские сообщения и могут прервать консольный запуск или обработку команды бота.
- **`ZoneInfoNotFoundError` для `Europe/Moscow`.** Если в системе нет базы часовых поясов, установите её для Python: `python -m pip install tzdata`.
- **Нужно выбрать режим.** Передайте ровно один флаг: `--cli` или `--bot`. Справка по запуску: `python main.py --help`.
